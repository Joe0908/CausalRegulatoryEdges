# Manuscript files

- `When_Does_a_Regulatory_Edge_Become_Causal_initial.md`: editable source.
- `When_Does_a_Regulatory_Edge_Become_Causal_initial.docx`: review copy built
  from the Markdown source.
- `When_Does_a_Regulatory_Edge_Become_Causal_initial.pdf`: fixed-layout review
  copy when LibreOffice is available at build time.
- `figures/figure1_study_design.png`: staged study design.
- `figures/figure2_network_state_summary.png`: network calibration, E1 and
  state-dependence summary.
- Figure 3 and Figure 4 are linked from the corresponding compact report
  directories so that one result has one canonical figure file.

Build the review copies from the repository root:

```bash
bash scripts/build_manuscript.sh
```

The manuscript is an initial scientific draft, not a submission-ready version.
Correspondence, acknowledgements, target-journal formatting, data archive DOI
and any collaborator contributions remain to be finalized.
